-## Brief Explanation
This repository contains the client-side JavaScript solutions for Lab #4a:
-**Q1 (`q1/`):** Interactive Text Changer using DOM manipulation (`getElementById` and `addEventListener`).
-**Q2 (`q2/`):** Smart Number Validator that validates empty or non-numeric inputs (`Number.isNaN`) and compares numbers against 10.
-**Q3 (`q3/`):** Dynamic Number Generator using a `for` loop (`1` to `5`) and `document.createElement()` without duplicating items on repeated clicks.

## Instructions to Run
1. Clone or download this repository to your local computer.
2. Open the respective folder (`q1`, `q2`, `q3`) and double-click `index.html` to run it in a web browser or open via **VS Code Live Server**.
3. Interact with the buttons and input fields on each page to view the output.
